# MIRAGE 🎥✨ - メディア管理システム

大学の映像制作サークル（県大TV）向けに設計された、SDカード・ポータブルSSD・外付けHDDなどの機材持ち出し状況および保存データ内容を管理するシネマティックWebアプリケーションです。

PC・スマートフォンの両方に完全対応（PWA対応）しており、GitHub Pagesで無料公開できます。また、Firebase（Cloud Firestore）と連携することで、部員全員の端末間でリアルタイムにデータが同期されます。

---

## 🌟 主な機能

### 1. メディア項目追加・編集機能
* 管理番号（例: `SD-01`, `SSD-02`）、機材名、メディア種別（SD / microSD / CFexpress / SSD / HDD / USB）を登録
* 容量（128GB, 1TB等）や規格スピード（V90 UHS-II, 1050MB/s等）のスペック管理
* 用途タグ（例: `α7SIII 4K120p対応`, `ドローン用`, `編集用SSD`）

### 2. 保存データの詳細記録（文字入力）
* メディア内に保存されている撮影素材の内容（撮影日、カメラ、シーン、フォーマット、取り込み状況など）をテキストで記録
* **PCに接続しなくてもスマホやPCから中身がひと目で確認可能**

### 3. 初期化ステータスの可視化（事故防止）
* 🟢 **初期化OK**: 空きメディア。フォーマットして撮影に使って良い状態
* 🟡 **要確認**: データが入っており、消去して良いか確認が必要な状態
* 🔴 **消去厳禁**: 納品前・未バックアップの重要データ。誤フォーマット防止アラート

### 4. 持ち出し・返却管理（ワンタップ操作）
* 「部室に保管中」か「貸出中」かを一目で表示
* 借りている部員名、返却予定日、企画名（例:「新歓PV撮影」）の記録
* 返却時に「フォーマットして返却する」にチェックを入れると自動で「🟢初期化OK」に更新

### 5. QRコードスキャン＆テプラ印刷対応
* スマホのカメラでSDカードやケースに貼ったQRコードをスキャンすると、**即座にそのメディアの持ち出し・内容更新画面が開きます**
* アプリ内でQRコード付き管理ラベルを表示・印刷可能

### 6. PWA（Progressive Web App）対応
* スマホ（iPhoneのSafari「ホーム画面に追加」、AndroidのChrome「アプリをインストール」）でネイティブアプリのように全画面で軽快に利用可能
* PCブラウザの大画面でも快適に一覧表示・検索・絞り込みが可能

## 🚀 デプロイとセットアップ手順

### ステップ 1: GitHub Pages への公開

1. このプロジェクトをGitHubのリポジトリにプッシュします。
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 県大TV メディア管理システム"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
2. GitHubのリポジトリ設定を開きます：
   * **Settings** > **Pages** に移動
   * **Build and deployment** の **Source** を **`GitHub Actions`** に設定
3. 自動的に `.github/workflows/deploy.yml` が実行され、数分で `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` に公開されます。

---

### ステップ 2: Firebase（Firestore）の接続（完全無料）

部員全員でリアルタイム同期を行うために、Firebase Firestore を利用します（初期状態では端末内のみ保存されるローカルモードで動作します）。

1. [Firebase Console](https://console.firebase.google.com/) にアクセスし、Googleアカウントでログイン
2. **「プロジェクトを追加」** をクリック（例: `kendaitv-media`）
3. プロジェクトが作成されたら、左メニューの **「Firestore Database」** をクリック ＞ **「データベースの作成」**
   * ロケーション: `asia-northeast1 (Tokyo)` を選択
   * セキュリティルール: **「テストモードで開始」** を選択（30日後に部内認証等を追加可能）
4. プロジェクトの概要（歯車アイコン）＞ **プロジェクトの設定** ＞ **マイアプリ** の **「ウェブ (`</>`)」** を追加
5. 表示された `firebaseConfig`（`apiKey`, `projectId` など）をコピー
6. アプリ右上の **⚙️（設定アイコン）** を開き、コピーした内容を貼り付けて **「保存して再読み込み」** を押せば接続完了です！
   * これで、部員Aがスマホで「持ち出し」を押すと、部室のPCでも即座に状態が切り替わります。
